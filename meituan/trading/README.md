# 虚拟操盘章程｜03690.HK 单账户双引擎

> 目标：用 1 年+ 的真实未来行情检验系统的交易能力。成绩单 = 收益、最大回撤、胜率、盈亏比、纪律执行率。

## 1. 账户口径（已确认）

- 标的：美团-W（03690.HK），1 手 = 100 股，货币港元。
- 初始虚拟资金：100,000 港元；持仓上限 10 手 = 1000 股。
- 起跑状态：2026-07-27 收盘后空仓；从下一个有效信号开始建仓。
- 成交规则：信号以收盘价形成，**次一交易日开盘价成交**；费用每边 0.15%（佣金+印花税+滑点简化）。
- 账户结构：单账户双引擎——趋势仓 + 波段仓共用 1000 股上限。趋势仓上限 700 股，波段仓上限 300 股。

## 2. 风格红线（不可违反）

- 只允许趋势跟随 / 波段操作；**禁止日内高频**：同一批仓位最少持有到次一交易日之后，波段仓最短持有 2 个交易日。
- 频率上限：每周新**开仓（买入）**订单 ≤ 3 笔；趋势仓只在周线信号触发后调整。风控离场单（硬性失效清仓、止损、目标位减仓/清仓、时间止损）**不占频率额度、任何时候都不得被频率限制拦截**——频率上限约束的是开风险的次数，不是关风险的能力。
- 先记录后成交：任何订单必须先写入 `orders.jsonl`（含理由/止损/目标），成交由脚本按次日开盘价结算，禁止事后补单。
- 单笔风险（v3.2 分层）：首笔与波段每笔亏损 ≤ 净值 1%；趋势第 2/3 批 ≤ 1.5%（其止损位于第 1 批成本上方，超额由浮盈承担）。股数 = floor(净值×预算 ÷ (参考价−止损) ÷ 100) × 100；预算摊不满 1 手时，若 1 手的绝对风险仍在该档预算内，允许最小 1 手（否则宽止损规则在 10 万净值下永远开不出仓）。波段 B 用半预算（1%/2），1 手兜底上限为全额 1%。
- 周线口径：本章程里所有写「周收盘」的规则（硬性失效 71.8、趋势止损/跟踪止损、60周线突破、第2/3批加仓触发）一律读 `data/chart_data.json` 的 `meta.confirmed_weekly_close`（及配套的 `confirmed_ma60`/`confirmed_ma30`），这个值永远是「最近一个已经真正走完的周」——当周还没走完（`meta.latest_week_complete=false`，例如今天只是周一）时自动回退到上一周的收盘，不会拿半根周K线去触发，也不会因为节假日导致某周最后交易日不是周五、而把那一周的收盘永久漏判（一旦下一周开始交易，上一周的行只会被当作"已收官"读取，绝不会被跳过评估）。日线信号（回踩企稳、波段止损/目标/时间止损）不受影响，照常每个交易日检查。

## 5. 文件与 schema

```text
trading/
  README.md        # 本章程
  account.json     # 当前账户：现金、持仓、净值（热数据，每次必读）
  orders.jsonl     # 订单状态账本（先记录后成交；脚本全量重写以反映 planned→filled 等状态流转）
  fills.jsonl      # 成交账本（脚本按次日开盘价结算；唯一 append-only 不可变账本，记实际成交量）
  equity.jsonl     # 每日净值曲线（同日重跑幂等覆盖当日行，跨日追加；只读尾部）
  performance.json # 成绩单：收益/回撤/胜率/盈亏比/暴露度（脚本生成）
```

账本审计口径：
- `fills.jsonl` 是唯一不可变审计账本，只追加、永不改写；`shares`/`fee` 按**实际成交量**记录，与现金流水可对账。
- `orders.jsonl` 是订单状态视图：状态流转（planned→filled/cancelled/partial_filled）必须改写原行，所以由脚本全量重写；「禁止事后补单/改单」指禁止人为篡改 signal_date/理由/止损等既定字段，不是禁止脚本更新状态。
- 审计完整性由 git 兜底：**每次 `trading_update.py` 运行后必须 commit `trading/` 目录**，历史版本即审计轨迹。
- 卖单若因持仓不足未能全部成交（正常规则下不可能，属异常），标记 `partial_filled` 并在成绩单 `alerts` 中大声报警，**不自动续单**，由人工核查；剩余仓位若离场条件仍成立，次日例行会重新发单。

订单字段：order_id, created_at, signal_date, engine(trend|swing), side(buy|sell), shares, rule, reason, entry_ref, stop, targets, status(planned|filled|cancelled|partial_filled)；partial_filled 时附 filled_shares/unfilled_shares。

## 6. 成绩单口径

- 净值 = 现金 + 持仓市值（按最新收盘）；收益率以净值曲线计算。
- 对照基准：03690.HK 买入持有（buy&hold）。
- 每次 `trading_update.py` 运行后刷新 `performance.json`；每周复盘必须把成绩单写进 updates。
