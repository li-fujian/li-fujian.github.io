## 已发现的规则问题

- 页面与章程对第二批加仓时点、首仓突破线和第三批触发条件存在冲突。
- 突破路径首仓止损约89.73或91.20，第二批写整体止损“上移到88”，实际可能放宽止损，且低于首仓成本，不能声称由浮盈覆盖。
- 波段A的80–84区间与79.5止损相距过近，下单前必须按实际成交价、费用、滑点及跳空重新计算风险，不能固定写赔率。
- 波段B按92买、86.5止损、96/100各卖半，毛盈亏比为1.0909；每边0.15%费用后为0.99085。1.5倍来自只用最终目标计算，与分批兑现规则不符；两个目标均实现的假设也不等于期望收益。
- 1手100股在92/86.5方案下，含模型费用的损失约576.78港元，超过10万净值的0.5%预算。所谓半仓兜底实际上突破半预算。
- “次日回踩不破”不能在该日开盘前已知，必须明确何时确认、何时成交，避免前视偏差。
- 周收盘止损加次日开盘执行不是保证止损价成交；1%风险只能是计划值。
