# 恒生电子 600570 日K

静态页，没有构建步骤。浏览器打开 `index.html`，或访问 https://li-fujian.github.io/hundsun/

默认纵轴是 15–30 元，每 1 元一条横线。逢 0、逢 5 为实线并标价，其余整数价位是淡虚线。红涨绿跌（收盘不低于开盘为红）。阶段高低点按左右各 N 根 K 线自动识别，N 可在页面上切换为 3、5、8。纵轴上下限在 `app.js` 的 `FOCUS_MIN`、`FOCUS_MAX`。

## 更新日K

只编辑 `data.js`：

1. 把 `AS_OF` 改成新的截止日期。
2. 在 `DATA` 末尾追加一行，日期必须晚于上一行：`["YYYY-MM-DD", 开盘, 最高, 最低, 收盘, 成交量]`。成交量单位是股，不是手。
3. 不要改写已经写入的历史价格。阶段高低点、均线、成交量会自动重算。
4. 可选：在 `KEY_LEVELS` 里调整手工关注价位，格式 `{ price, date, label }`。

行情是腾讯财经 `sh600570` 前复权日线。成交量用新浪的当日成交股数，现金分红不缩放成交量。

前复权把除息前的价格下移，最新价仍是成交价。对照不复权：2026-06-09 之前开高低收低 0.25 元，2026-06-09 至 2026-10-21 低 0.05 元，2026-10-22 起相同。追加新 K 线时继续用前复权，不要把已经写入的历史价改回成交价。
