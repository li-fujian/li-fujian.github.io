# 科创50周线操作台

`scripts/build_strategy.py` 生成模型信号和历史回测；`dashboard.json` 是页面发布的数据快照。页面显示的持仓是模型推演，不连接实际证券账户。

页面会在加载后按上海时间、收盘时间15:00和上交所交易日历检查行情日期。加载失败、行情落后、日历未覆盖当前年份或开盘信号已经错过执行时点时，暂停显示操作指令。节假日不会仅因日历天数较多就被判为数据过期。网页保持打开时，每分钟复核一次；新数据发布后刷新页面即可载入。

`trading-calendar.json` 目前维护2026年上交所休市区间及官方来源，周六日始终休市。新增年度时应依据交易所公告添加该年度的`closures`和`sources`，保留旧年度数据；缺失年度不会默认当成正常交易日。

自动工作流在每个周一至周五的北京时间16:37刷新快照；用户的周线决策频率不变。构建入口的日线必须已经收盘，不能用盘中日线生成最终周线信号。

验证命令（无需额外依赖）：

```powershell
node --test kc50-weekly/tests/page.test.cjs
python -B -m unittest discover -s kc50-weekly/tests -p 'test_*.py'
```

未平仓记录的`sell_date`、`sell_price`是回测期末估值，只有`status=closed`才表示真实的模型退出；前端据此区分“持有中/浮动收益”和已平仓交易。
