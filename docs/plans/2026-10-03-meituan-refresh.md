# 美团页面修复与数据更新

目标：修正已确认的分析错误，用可核对的数据生成简洁页面，保留旧研究记录。

实施步骤：
1. 保存旧配置、图表和模拟盘为历史快照，标注不再作为当前信号。
2. 建立腾讯日/周线、腾讯快照、新浪快照的校验链。核对港交所交易日历、日期、OHLC、成交量、日周聚合；失败不覆盖页面数据。
3. 由完整周线重算 MA5/10/20/30/60、MACD；未收官周不生成周线判断。数值、状态和文字使用同一数据对象。
4. 按公司二季报 PDF 第 1–3 页核对季度、半年度和分部指标，保留人民币千元原值与来源；不将核心本地商业等同于外卖单项。
5. 页面收敛为状态、周线图、财报、核验说明；旧价位只用于复盘，不再给出主观概率或未经验证的交易指令。
6. 替换复制 Gitee 旧页面的工作流，定时执行本仓库校验与生成脚本。
7. 验证失效保护、节假日/半日市、日周聚合、数值与文案、费用公式、网页桌面及移动端显示。

边界：不修改其他策略；不伪造历史订单或把零成交模拟盘刷新成当前业绩；本次不声称完成交易引擎回测。
