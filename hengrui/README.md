# 恒瑞医药 600276 日K

静态页，没有构建步骤。浏览器打开 `index.html`，或访问 https://li-fujian.github.io/hengrui/

默认纵轴是 40–60 元，每 1 元一条横线。近六个月前复权高低是 41.89–58.00，40 和 60 是包住这段波动、并留出约 2 元空白的整数边界。逢 0、逢 5 为实线并标价，其余整数价位是淡虚线。红涨绿跌（收盘不低于开盘为红）。阶段高低点按左右各 N 根 K 线自动识别，N 可在页面上切换为 3、5、8。纵轴上下限在 `app.js` 的 `FOCUS_MIN`、`FOCUS_MAX`，格距在 `GRID_STEP`。

## 前复权

价格是腾讯财经 `sh600276` 日线的前复权（`fqkline` 参数 `qfq`）。这是差额复权，不是把 Yahoo 未复权 OHLC 直接拿来用。

窗口里只有一次现金红利，没有送转股：

- 2026-05-27 除息，每股 0.20 元。这一天之前的开高低收减去 0.20 元，当天及之后保持成交价。

所以最新收盘等于实际成交价，更早的价格被下移，除息日两边能接上。成交量用新浪当日成交股数，现金红利不缩放成交量。腾讯返回的成交量单位是手，而且会四舍五入，所以不写入 `data.js`。

抽样对照（不复权收盘来自新浪，与 Yahoo 未复权收盘一致）：

| 日期 | 不复权收盘 | 前复权收盘 | 算法 |
| --- | ---: | ---: | --- |
| 2026-05-18 | 52.43 | 52.23 | 52.43 − 0.20 |
| 2026-05-26 | 49.20 | 49.00 | 49.20 − 0.20 |
| 2026-05-27 | 50.37 | 50.37 | 除息日，等于成交价 |
| 2026-11-16 | 48.02 | 48.02 | 最新成交价 |

Yahoo `adjclose` 是比例复权。2026-05-18 的 adjclose 是 52.2169，与上表 52.23 差 0.013 元。东财 `push2his`（`fqt=1`）这次没有连上，上面的对照是新浪 / Yahoo 未复权价加 Yahoo 红利事件。

## 更新日K

没有新的现金红利时，只编辑 `data.js`：

1. 把 `AS_OF` 改成新的截止日期。
2. 在 `DATA` 末尾追加一行，日期必须晚于上一行：`["YYYY-MM-DD", 开盘, 最高, 最低, 收盘, 成交量]`。成交量单位是股，不是手。追加的必须是前复权价。没有新红利时，前复权价就是成交价。
3. 不要改写已经写入的历史价格。阶段高低点、均线、成交量会自动重算。
4. 可选：在 `KEY_LEVELS` 里调整手工关注价位，格式 `{ price, date, label }`，`price` 要等于该日最高价或最低价。

除息之后，旧的前复权价全部要下调。不要只追加除息日那一根。在仓库根目录重算：

```powershell
python scripts/update_study_klines.py hengrui
node --test hengrui/tests/page.test.cjs
```

脚本会拉腾讯前复权、新浪成交股数和 Yahoo 红利，核对「未复权价 − 其后现金红利」与腾讯前复权逐根一致，再写回 `data.js`。Yahoo `adjclose` 是比例复权，脚本按 `(除息前收盘 − 红利) / 除息前收盘` 连乘来核对它，不拿它和腾讯的差额前复权比一个固定差额。若出现送转股，脚本会停下来，不覆盖文件。
